## 🛠️ 2. 핵심 기술적 도전 및 문제 해결 (Tech Highlights)

### ① 기하학 기반의 물리적 부피 보존 및 동적 절단
- **문제:** 물방울이 합쳐지거나 잘릴 때 스케일이 선형(Linear)으로 변하면 액체 특유의 부피감이 깨지고 크기 왜곡이 발생함.
- **해결:** 
  - 2D 원의 면적 공식($\pi r^2$)에 기반하여 융합 시 $R = \sqrt{r_1^2 + r_2^2}$ 공식을 도출해 엄밀한 면적 보존 구현.
  - 마우스 드래그 궤적과 원형 중심 간의 거리를 계산하여 원의 현(Chord) 기하 분할 비율을 산출, 칼날 선형을 기준으로 2개의 작은 방울로 물리 분할.
- **결과:** 자르고 합치는 과정에서 총 부피가 100% 보존되는 신뢰성 높은 액체 상호작용 달성.

### ② 몬테카를로 격자 샘플링 기반의 실시간 형태 판정 (IoU)
- **문제:** 다각형 불리언(CSG) 연산 라이브러리는 2D 환경에서 연산 비용이 크고, 원형 물체가 각진 모서리에 닿을 때 외곽선 삐져나옴으로 인한 불합리한 감점 발생.
- **해결:** 
  - 타겟 콜라이더 바운딩 박스 내부에 가상 프로브 포인트들을 투사하여 채움률을 계산하는 수치 적분 샘플링 알고리즘 구축.
  - `ClosestPoint`를 활용해 콜라이더 외곽선 표면으로부터 0.2m 이내의 자연스러운 삐져나옴은 감점하지 않는 '오차 완충 지대(Tolerance Buffer)' 설계.
- **결과:** 복잡한 외곽선도 60fps 환경에서 가비지 없이 실시간 판정하며, 플레이어 체감 난이도의 불합리함 해소.

### ③ 레벨 디자인 생산성을 위한 자체 씬 뷰 스탬프 에디터 툴 제작
- **문제:** 일반 타일맵은 1x1 격자에 강제 정렬되어 부피가 다른 원형들을 자연스럽게 배치하기 어렵고, 디자이너가 플레이어가 만들 수 없는 임의의 크기($r=0.63$ 등)의 풀 수 없는 스테이지를 만들 위험이 있음.
- **해결:** 
  - 플레이어가 게임 내에서 융합/절단으로 도달 가능한 부피 단계($r = 0.5 \times \sqrt{V}$)로만 원형 크기가 스냅되는 자체 에디터 스탬프 툴(`TargetShapeBuilder`) 개발.
  - Scene 뷰 마우스 휠 및 단축키 인터랙션을 통해 즉석에서 `CompositeCollider2D` 연동 다각형을 생성하고 필요 물방울 수를 자동 계산하도록 파이프라인 구축.
- **결과:** 스테이지 1개 제작 시간을 10분에서 30초 단위로 80% 이상 단축.

### ④ 메멘토 패턴(Memento) 기반 상태 복구 및 아키텍처 모듈화
- **문제:** 동적 물리 조인트(FixedJoint2D)가 얽힌 오브젝트들을 물리 엔진 실행 중에 되돌릴 때 참조 손실 및 좌표 왜곡 발생.
- **해결:** 
  - 물방울의 좌표, 스케일, 연결 ID를 구조체화하여 스택에 보관하는 메멘토 패턴 `UndoManager` 구현 (게임 시작 상태 영구 보존 및 충돌 루프 락 탑재).
  - 단일 책임 원칙(SRP)에 따라 `StageManager`에서 3초 버티기 검증(`ClearHoldValidator`), 인트로 연출(`StageIntroCountdown`), 타이머(`StageTimer`)를 분리하고 C# 이벤트(`Action`)로 통신하도록 디커플링.
- **결과:** 코드 간 결합도(Coupling)를 낮추고, 키 연타 버그 및 비동기 코루틴 꼬임 현상 원천 차단.

## 🏛️ 3. 시스템 아키텍처 (클래스 구조도)

```text
[StageManager] (중앙 오케스트라 사령탑)
  ├── 📢 C# Event 수신 ── [ClearHoldValidator] (3-2-1 안정성 검증기)
  ├── ⏱️ 타이머 제어 ─── [StageTimer] (일시정지 지원 카운트다운)
  ├── 🎬 인트로 연출 ─── [StageIntroCountdown] (시작 3-2-1 연출)
  └── 🎨 형태 주입 ──── [Stage Prefabs] (순수 데이터/콜라이더 껍데기)
                             │
                             ▼
                     [ShapeMatcher] (독립 판정 엔진)
```

## 🎮 4. 조작 가이드 (Controls)

| 키 입력 | 동작 |
| :--- | :--- |
| **마우스 이동** | 국물 위의 기름방울 밀기 |
| **좌클릭 드래그** | 물방울 완전 융합 (합치기) |
| **우클릭 드래그** | 표면장력 접착 결합 (붙이기) |
| **Space + 드래그** | 칼날 슬라이스 절단 (자르기) |
| **마우스 휠** | 카메라 줌인 / 줌아웃 (CAD 스타일) |
| **휠 클릭 드래그** | 카메라 시점 이동 (패닝) |
| **Ctrl + 휠** | 마우스 밀기 반경 크기 조절 |
| **Z 키** | 직전 상태로 되돌리기 (Undo) |
| **R 키** | 스테이지 즉시 재시작 (Restart) |
| **F1 키** | 【Debug】 스테이지 즉시 스킵 및 클리어 |
| **Tab 키** | 조작 안내 패널 보이기 / 숨기기 |
| **L 키** | 인게임 언어 전환 (한국어 ↔ 日本語) |
| **ESC 키** | 일시정지 메뉴 (Pause) |
