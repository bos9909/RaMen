## 🛠️ 2. 主要な技術的挑戦と課題解決 (Technical Highlights)

### ① 幾何学計算に基づく体積保存および動的スライス切断
- **課題:** 油滴の融合や切断時にスケールを線形(Linear)に変化させると、液体の体積感が損なわれ、不自然なサイズ歪みが発生する。
- **解決策:** 
  - 2D円の面積公式（$\pi r^2$）を基に、合体時に $R = \sqrt{r_1^2 + r_2^2}$ を適用し、厳密な面積（体積）保存を実現。
  - マウスのドラッグ軌跡と円の中心との距離から「円の弦（Chord）」の幾何学的分割比率をリアルタイムに計算し、切断線に沿って2つの物理的な油滴へ動的分割。
- **結果:** スライス切断や合体を繰り返しても、全体の総体積が100%維持される高精度な液体インタラクションを達成。

### ② モンテカルロ格子サンプリングによるリアルタイム形状判定 (IoU)
- **課題:** ポリゴンブーリアン（CSG）演算は2D環境において計算負荷が高く、円形の油滴が角張った角に接触した際、外枠へのはみ出しによる理不尽な減点が発生しやすい。
- **解決策:** 
  - ターゲットコライダーのバウンディングボックス内に仮想プローブポイントを格子状に投影し、充填率を数値積分で算出するサンプリングアルゴリズムを構築。
  - `ClosestPoint` APIを活用し、外枠表面から0.2m以内の自然なはみ出し（表面張力による誤差）を許容する「許容誤差バッファゾーン（Tolerance Buffer）」を設計。
- **結果:** 複雑なシルエットでも60fps環境でGC Alloc（ガベージ）を発生させずに判定し、プレイヤーが納得できるゲームバランスを実現。

### ③ レベルデザインの生産性向上のための自作エディタースタンプツール
- **課題:** 通常のタイルマップは1x1グリッドに拘束されるため、サイズの異なる円を自由な角度で配置しづらく、プレイヤーが物理的に作成不可能な任意のサイズ（$r=0.63$ など）の「クリア不能なステージ」を作成してしまうリスクがあった。
- **解決策:** 
  - プレイヤーがゲーム内で合体・切断により到達可能な体積ステップ（$r = 0.5 \times \sqrt{V}$）にのみスナップする、独自のシーンビュースタンプツール（`TargetShapeBuilder`）を自作。
  - シーンビュー上でのホイール操作・ショートカットにより、即座に `CompositeCollider2D` と連携する外枠ポリゴンを生成し、ステージクリアに必要な油滴数を自動計算するパイプラインを構築。
- **結果:** ステージ1つの制作時間を10分から30秒以内へと短縮（作業効率80%向上）。

### ④ メメントパターン（Memento）による状態復元と疎結合アーキテクチャ
- **課題:** 動的な物理ジョイント（FixedJoint2D）で結合された複数オブジェクトを、物理シミュレーション実行中にアンドゥ（Undo）する際、参照の喪失や座標の不整合が発生する。
- **解決策:** 
  - 油滴の座標、スケール、結合IDを軽量な構造体としてスタック管理するメメントパターンの `UndoManager` を実装（ゲーム開始時の初期状態保護および衝突ループ防止ロックを搭載）。
  - 単一責任の原則（SRP）に基づき、`StageManager` から3秒維持判定（`ClearHoldValidator`）、開始演出（`StageIntroCountdown`）、タイマー（`StageTimer`）を分離し、C#の `Action` イベントによる疎結合（Loose Coupling）な設計を採用。
- **結果:** スパゲッティコード化を防止し、キーの連打や非同期コルーチンの重複実行による進行不能バグを根本的に排除。

## 🏛️ 3. システムアーキテクチャ (クラス構成図)

```text
[StageManager] (全体を統括する中央オーケストレーター)
  ├── 📢 C# Event 受信 ── [ClearHoldValidator] (3-2-1 安定性維持判定)
  ├── ⏱️ タイマー制御 ─── [StageTimer] (一時停止対応カウントダウン)
  ├── 🎬 イントロ演出 ─── [StageIntroCountdown] (開始 3-2-1 演出)
  └── 🎨 形状の注入 ──── [Stage Prefabs] (純粋なコライダー/表示データ)
                             │
                             ▼
                     [ShapeMatcher] (独立した形状判定エンジン)
```

## 🎮 4. 操作方法 (Controls)

| 入力 (Input) | 動作 (Action) |
| :--- | :--- |
| **マウス移動** | スープ上の油滴を押し動かす |
| **左クリック + ドラッグ** | 油滴の完全融合（合体） |
| **右クリック + ドラッグ** | 表面張力による吸着結合（くっつける） |
| **Space + ドラッグ** | 刃によるスライス切断（分ける） |
| **マウスホイール** | カメラのズームイン / ズームアウト (CADスタイル) |
| **ホイール長押しドラッグ** | カメラの視点移動（パンニング） |
| **Ctrl + ホイール** | 押し出し影響範囲（リング）の拡大・縮小 |
| **Z キー** | 直前の状態に戻す (Undo) |
| **R キー** | ステージの即時リトライ (Restart) |
| **F1 キー** | 【Debug】ステージの強制スキップ・即時クリア |
| **Tab キー** | 操作ガイドHUDの表示 / 非表示切り替え |
| **L キー** | 言語切り替え (日本語 ↔ 韓国語) |
| **ESC キー** | ポーズメニューの表示 (Pause) |
